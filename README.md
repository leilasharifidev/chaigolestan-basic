# Golestan Tea Website 🍃

A responsive tea brand website inspired by Golestan Tea, built with HTML and CSS. This project focuses on clean UI design, structured layouts, and responsive styling to provide a consistent browsing experience across desktop, tablet, and mobile devices.

## ✨ Features

- **Responsive Design** — Adapts to different screen sizes and devices.
- **Clean UI** — A structured and visually appealing layout.
- **Semantic HTML** — Organized markup for better readability and maintainability.
- **Custom CSS Styling** — Layouts, typography, spacing, and visual elements styled with CSS.
- **Cross-Device Compatibility** — Designed to work across common screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone [https://github.com/leilasharifidev/chaigolestan-basic.git]
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.

## 📱 Responsive Layout

The website is designed to provide a consistent user experience across desktop, tablet, and mobile screen sizes.
